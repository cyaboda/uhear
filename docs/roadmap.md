# Roadmap y estado

## Entregado local, sujeto a pruebas registradas en README
Registro/login/logout, perfil de artista, subida MP3/WAV, publicación pública/privada/no listada, búsqueda título/artista/género, reproducción con Range, favoritos, playlists y métricas básicas. Interfaz responsive, temas claro/oscuro, cola, siguiente/anterior, aleatorio, repetición, volumen y Media Session donde esté disponible.

## Próximo hito: cloud
Portar a Next.js/TypeScript, conectar exclusivamente Supabase UHEAR, migraciones normalizadas con RLS, Auth con confirmación de correo y recuperación, almacenamiento privado y worker de validación/transcodificación. Configurar HTTPS, correo, cuotas, backups, logs y CI. No está desplegado públicamente.

## Posterior
Álbumes/EP, portadas y fotografías propias, equipos de artistas, follows, historial visible, recomendaciones por preferencias, programación, panel admin con auditoría, reportes/retiradas, verificación y moderación. Sin integración de distribución a terceros. Seguridad y derechos necesitan procesos operativos además de código.
